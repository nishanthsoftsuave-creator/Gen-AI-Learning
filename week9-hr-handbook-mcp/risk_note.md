Maintainer: Local internal educational implementation written for this Week 9 exercise (source: Agentic Ai/mcp_policy_registry_server.py in this repository); it is not a third-party/external server and no external maintainer is claimed.
Reach: Read-only access to one local data file (Agentic Ai/policy_registry.json: policy ids, versions, effective dates, statuses); no employee PII, no database, no other systems, and no network egress -- the server makes no external requests of its own.
Logging: Tool name, policy id, arguments, timestamps and error text are appended to Agentic Ai/output/mcp_trace.jsonl (server stderr to output/mcp_hr-policy-registry_stderr.log); this server holds no secrets or tokens and logs none.
Stolen token: There is NO authentication token in this local exercise -- the server is a config-launched stdio subprocess with no network listener; if a token were ever introduced later, a stolen one would allow only the four read-only registry lookups within its granted scope.
Decision: Ship for this local educational exercise only; do NOT deploy further until source review, authentication and authorization testing, least-privilege token scope, and logging review are all in place.
